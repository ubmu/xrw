xrw
====
This library provides structural I/O for binary formats.

`xrw` parses any structured binary format into a uniform index of blocks without reading payloads, enabling fast querying and manipulation.

Currently supported families include RIFF, IFF, AIFF/AIFC, RF64/BW64, and Sony Wave64. Support for QuickTime/ISOBMFF, PNG, JPEG, EBML/Matroska, FLAC, Ogg, TIFF/IFD, ASF, MXF, and more is planned.

See the [documentation](https://docs.rs/xrw) for the complete reference.
